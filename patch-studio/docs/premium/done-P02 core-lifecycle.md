## Stap 0: contracten voor de andere pakketten
- **C1 Logger** `includes/class-logger.php`: `Logger::error/warning/info/debug/notice/critical( $event, $context )`, source
  `borduur-patch-studio` (wc_get_logger), drempel `admin.logLevel` (standaard `error`, filter `bps_log_level`),
  context door redactie: sleutels/tokens/wachtwoorden/nonces → `[redacted]`, e-mail/IP → korte HMAC-hash, `sk-…`,
  Bearer-tokens en opgeslagen AI-sleutels uit vrije tekst, exceptions → klasse/boodschap/bestand:regel. Zonder WC alleen
  `error_log` als `WP_DEBUG_LOG` aan staat. Gooit nooit. `Logger::set_writer()` voor tests, `Logger::logs_url()`.
- **C2** `Plugin::modules()`, `Plugin::owned_data()` (+ filter `bps_owned_data` en statische `owned_data()` per klasse,
  die ook in uninstall werkt), actie `bps_upgraded( $from, $to )`, `register_always()` per module.
- **C9** `BorduurPatchStudio\I18n` staat eerst in `Plugin::COMPONENTS` en wordt met `I18n::boot()` gestart (zodra P11
  de klasse levert; tot dan meldt de plugin hem als ontbrekend onderdeel).
